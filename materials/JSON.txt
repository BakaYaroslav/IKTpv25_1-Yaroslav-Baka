🌐 JSON (JavaScript Object Notation) в Python
1. Что такое JSON?

JSON — это лёгкий формат данных, который широко используется для:

Хранения данных в файлах.

Обмена данными между программами (например, через веб-сервисы или API).

🤝 JSON и Python

JSON напрямую связан с Python, так как его структура соответствует типам Python:

Python тип	Соответствие в JSON	Пример
dict (словарь)	JSON-объект	{"имя": "Анна"}
list (список)	JSON-массив	["Мария", "Юрий"]
True / False	true / false	Логические значения
None	null	Отсутствие значения
2. Работа с JSON в Python

Для работы с JSON используется стандартный модуль json.

2.1. Импорт
import json
import requests  # для запросов к API

2.2. Python объект ↔ JSON строка

json.dumps() — конвертирует Python объект в JSON-строку.

json.loads() — конвертирует JSON-строку обратно в Python объект.

import json

data = {"имя": "Анна", "возраст": 25, "замужем": False}

# Python -> JSON строка
json_string = json.dumps(data)

# JSON строка -> Python объект
data_back = json.loads(json_string)


Красивое форматирование JSON:

print(json.dumps(data, indent=2, sort_keys=True))


indent=2 — отступ для читаемости.

sort_keys=True — сортировка ключей по алфавиту.

2.3. Работа с JSON-файлами

json.dump() — записывает Python объект в файл в формате JSON.

json.load() — читает JSON из файла и преобразует в Python объект.

klass = { 
    "учитель": "Тамм", 
    "ученики": [{"имя": "Мария", "оценка": 5}, {"имя": "Юрий", "оценка": 4}] 
}

with open("klass.json", "w") as f: 
    json.dump(klass, f, indent=2)


JSON поддерживает вложенные структуры, аналогичные сложным словарям и спискам в Python.

3. 🌤 Пример: использование API прогноза погоды

JSON незаменим при работе с API, например, для получения прогноза погоды с OpenWeatherMap.

Цель проекта: запросить город, сделать API-запрос и вывести погоду.

import requests

api_key = "ВАШ_API_KEY"  # замените на свой ключ
city = input("Введите название города: ")
url = f"http://api.openweathermap.org/data/2.5/weather?q={city}&appid={api_key}&units=metric&lang=ru"

response = requests.get(url)
data = response.json()  # конвертируем JSON в Python словарь

if data.get("cod") != "404":
    main = data["main"]
    temperature = main["temp"]
    description = data["weather"][0]["description"]
    wind_speed = data["wind"]["speed"]

    print(f"Температура: {temperature}°C")
    print(f"Описание: {description.capitalize()}")
    print(f"Скорость ветра: {wind_speed} м/с")
else:
    print("Город не найден. Проверьте правильность названия.")


Опционально: сохранить JSON в файл для дальнейшего анализа.

🌐 JSON (JavaScript Object Notation) Pythonis
1. Mis on JSON?
JSON (JavaScript Object Notation) on lihtne ja kerge andmevorming, mida kasutatakse laialdaselt.

Andmete salvestamiseks failides.

Andmete vahetamiseks programmide (näiteks veebiteenuste ehk API-de) vahel.

🤝 JSON-i ja Pythoni Sarnasused
JSON on Pythoniga loomulikult seotud, kuna selle struktuur peegeldab otseselt Pythoni andmetüüpe:

Pythoni tüüp	JSON-i vaste	Näide
dict (sõnastik)	JSON-objekt	{"nimi": "Anna"}
list (järjend)	JSON-massiiv	["Mari", "Jüri"]
True/False	true/false	Loogikaväärtused
None	null	Väärtuse puudumine
2. JSON-i Kasutamine Pythonis
JSON-andmete lugemiseks ja kirjutamiseks kasutatakse standardmoodulit json.

2.1. Importimine ja Seadistamine
import json
import requests # Vajalik API-päringute tegemiseks
2.2. Python andmestik ↔️ JSON string
Kahte peamist meetodit kasutatakse andmete konverteerimiseks:

Meetod	Eesmärk	Näide
.dumps()	Dump string – konverteerib Pythoni objekti JSON-stringiks.	json_string = json.dumps(andmed)
.loads()	Load string – konverteerib JSON-stringi tagasi Pythoni objektiks (sõnastikuks/listiks).	andmed = json.loads(json_string)
Ilusam Formaat: Saab luua loetavama (indentitud) JSON-stringi.

andmed = {"nimi": "Anna", "vanus": 25, "abielus": False} 
print(json.dumps(andmed, indent=2, sort_keys=True))
# indent=2 määrab taanderea suuruse.
2.3. Töö JSON-failidega
Failidega tööks kasutatakse meetodeid, mis võtavad lisaks andmetele ka failiobjekti (mille saab lahti with open abil):

Meetod	Eesmärk	Kasutamine
.dump()	Kirjutab Pythoni objekti (nt. sõnastiku) otse JSON-faili.	json.dump(andmed, f)
.load()	Loeb andmed otse JSON-failist ja teisendab need Pythoni objektiks.	andmed_failist = json.load(f)
Keerulisemad Andmestruktuurid: JSON toetab sisesõnastikke ja sisesisese (nested) struktuuri, mis vastab keerukatele Pythoni sõnastikele/listidele.

klass = { 
    "opetaja": "Tamm", 
    "opilased": [{"nimi": "Mari", "hinne": 5}, {"nimi": "Jüri", "hinne": 4}] 
} 
with open("klass.json", "w") as f: 
    json.dump(klass, f, indent=2)
