?? Tsüklid Pythonis — WHILE, WHILE TRUE ja FOR
?? 1. Tsükli WHILE kasutamine tingimusega
print("Arvuta peast! ... 4 * 100 - 55")

oige_vastus = 4 * 100 - 55       # ?? Arvutame õige vastuse ette
vastus = int(input("Lahenda ülesanne ... "))  # ????? Kasutaja sisestab oma vastuse
k = 1                            # ?? Loeme, mitmes katse see on

# ?? Kuni vastus EI OLE õige, kordame tsüklit
while vastus != oige_vastus:
    print("Viga! Sisesta õige vastus ...")   # ?? Vale vastus
    vastus = int(input("Sisesta vastus ... ")) # ?? Küsi uuesti
    k += 1

print("? Õige vastus! Katsed olid kokku:", k)
?? Selgitus:
while kontrollib tingimust enne iga tsükli käivitust.

Kui tingimus on tõene (True), tsükkel jätkub.

Kui tingimus muutub vääraks (False), tsükkel lõpeb.

Seda kasutatakse siis, kui teame lõpetamise tingimust, aga ei tea täpselt, mitu korda tsükkel töötab.

?? 2. Sama näide, kuid kasutades while True
print("Arvuta peast! ... 4 * 100 - 55")

oige_vastus = 4 * 100 - 55
k = 1

while True:   # ?? Tsükkel töötab lõpmatuseni
    vastus = int(input("Lahenda ülesanne ... "))
    
    if vastus == oige_vastus:   # ? Kui õige, siis katkestame tsükli
        print("Õige vastus! Katsed olid kokku:", k)
        break                   # ? Tsükli katkestamine
    else:
        print("Viga! Proovi uuesti ??")
        k += 1
?? Selgitus:
while True tähendab “tee seni, kuni ma käsin lõpetada”.

Tsükkel katkestatakse käsuga break.

Seda kasutatakse, kui lõpetamistingimus tekib tsükli sees, mitte alguses.
Näiteks kasutaja vajutab nuppu, annab õige vastuse või sisestab sõna "stop".

?? 3. Paaritud arvud kuni 30 (WHILE-tsükliga)
x = 0
while x < 30:             # ?? Tsükkel töötab, kuni x < 30
    if x % 2 == 1:        # ?? Kontrollime, kas arv on paaritu
        print(x, end=" ") # ?? Väljastame sama reale
    x += 1                # ? Suurendame x ühe võrra

?? 4. Sama ülesanne while True abil
x = 0
while True:
    if x % 2 == 1:
        print(x, end=" ")
    if x == 30:          # ? Kui jõuame 30-ni, katkestame tsükli
        break
    x += 1
?? Tulemus on sama, kuid nüüd kasutatakse tsüklit, mis töötab seni, kuni break seda lõpetab.

?? 5. Sama ülesanne FOR-tsükliga
for i in range(1, 31, 2):   # ?? Algab 1-st, kuni 31-ni, samm 2
    print(i, end=" ")

?? Millal kasutada millist tsüklit?
Tsükkel	Millal kasutada	Näide
while	Kui ei tea täpselt, mitu korda tsükkel peab korduma, aga tead lõpetamise tingimust.	Küsid kasutajalt, kuni ta sisestab õige vastuse.
while True + break	Kui lõpetamistingimus tekib tsükli sees.	Mängu katkestamine, kui mängija vajutab “exit”.
for	Kui tead täpselt, mitu korda tsükkel töötab.	Arvude väljastamine 1-st 30-ni.
?? Kokkuvõte
Tsüklid aitavad automaatselt korrata tegevusi.

while töötab seni, kuni tingimus on tõene.

while True töötab lõpmatuseni, kuni kasutad break.

for sobib kõige paremini siis, kui tead täpset korduste arvu.

Tsükleid kasutades ära unusta tingimusi ja muutujate muutmist, muidu võib programm jääda igavesti tööle
