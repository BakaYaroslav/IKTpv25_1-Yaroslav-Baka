🗂 Словарь в Python (dict)

Словарь (dictionary, или dict()) — это структура данных в Python, основанная на ключах и значениях.
Идеально подходит для хранения и работы с парами «ключ: значение», обеспечивая быстрый доступ к конкретным данным.

🛠 I. Создание словаря

Есть несколько способов создать словарь:

Пустой словарь (самый распространённый)

data = {}


С ключами и значениями

data = {'name': 'Mari', 'age': 25, 'language': 'Estonian'}


С помощью функции dict()
(удобно при работе с JSON)

data = dict(name='Mari', age=25, language='Estonian')

🔑 II. Доступ к данным и работа с ними
1. Доступ к значениям
Метод	Описание	Пример
Квадратные скобки []	Ищет значение по ключу. Ошибка, если ключ отсутствует.	print(data['name'])
.get(ключ, [по умолчанию])	Ищет значение, если ключ отсутствует, возвращает None или указанное значение.	data.get('address', 'Не задано')
2. Изменение и добавление значений
data['name'] = 'Kati'          # изменение значения
data['email'] = 'kati@example.com'  # добавление новой пары
# Результат: {'name': 'Kati', 'age': 25, 'language': 'Estonian', 'email': 'kati@example.com'}

3. Удаление элементов
Метод	Описание	Пример
del	Удаляет ключ и значение	del data['age']
.pop(ключ)	Удаляет ключ и возвращает его значение	data.pop('language')
.clear()	Очищает весь словарь	data.clear()
🔁 III. Перебор и проверка
1. Перебор (итерация)
# перебор ключей
for key in data:
    print(key)

# перебор ключей и значений
for key, value in data.items():
    print(f'{key}: {value}')

2. Проверка существования ключа
if 'name' in data:
    print('Ключ "name" существует!')

🗂 IV. Полезные методы
Метод	Описание	Пример
.keys()	Возвращает все ключи	print(data.keys())
.values()	Возвращает все значения	print(data.values())
.update(другой_словарь)	Добавляет или обновляет пары ключ-значение	data.update({'age': 30})
Пример: Создание словаря из списка (чтение файла)
read = ['What is Python?:programming language', 'Capital of Estonia?:Tallinn']

kus_vas = {}  # создаём пустой словарь
for line in read:
    question, answer = line.split(':')  # делим строку на два элемента
    kus_vas[question.strip()] = answer.strip()  # добавляем в словарь

print(kus_vas)
# Результат: {'What is Python?': 'programming language', 'Capital of Estonia?': 'Tallinn'}

🎯 Вывод

dict() помогает хранить данные в виде пар «ключ-значение».

Словарь полезен для быстрого доступа к конкретной информации (например, данные пользователя, настройки, вопросы/ответы и т.д.).
